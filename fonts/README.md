# Local font subsets

Unmodified Latin WOFF2 files downloaded from the Google Fonts requests in the
original page on 2026-09-26. Fraunces retains its optical-size axis, normal
weight 500 and italic weight 400. Nunito covers weights 500–700. Licenses are
included alongside the fonts; the build copies them to `dist/licenses/`.

- [Fraunces normal](https://fonts.gstatic.com/s/fraunces/v38/6NUu8FyLNQOQZAnv9bYEvDiIdE9Ea92uemAk_WBq8U_9v0c2Wa0K7iN7iQcIfJD58ngB1Yc7qv8oRcTn.woff2)
